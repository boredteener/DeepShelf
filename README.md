# DeepShelf

DeepShelf is a strange-game discovery archive for obscure, cult, forgotten, regional, and interesting games — built for finding the kind of game you can almost remember.

## Explore DeepShelf

https://boredteener.github.io/DeepShelf/

## What's new in 1.1

- **Download / Play** has been added to supported game pages.
- **Downloadables** is a new browse section for seeing every game that currently has a download or play option in one place.
- An optional **feedback card** lets visitors suggest games, report things that could be improved, and leave other ideas.
- The public interface has been cleaned up so the archive is simpler for visitors to browse.

More games, links, and archive improvements will continue to be added over time.
